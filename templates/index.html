🎮 Number Guess Game

📖 How To Play The Game

🇬🇧 English

🎯 Single Player Mode

Enter your name and start guessing the secret number between 1 and 100. If the correct number is greater than your guess, a message saying "Too Low" will appear below the Guess button. If the correct number is smaller than your guess, a message saying "Too High" will appear below the Guess button. Keep guessing until you find the correct number. Your goal is to win in the fewest attempts possible and secure a place on the leaderboard.

🎮 Multiplayer Mode

One player creates a room and shares the room code with friends. All players join using the room code. Each player sets a secret number. The game can only start when every player has set their secret number. Players must guess each other's secret numbers. The player who completes all guesses in the fewest attempts becomes the winner.

🇧🇩 বাংলা

🎯 সিঙ্গেল প্লেয়ার মোড

নিজের নাম লিখে ১ থেকে ১০০-এর মধ্যে একটি গোপন সংখ্যা অনুমান করো। যদি সঠিক সংখ্যা তোমার অনুমানের চেয়ে বড় হয়, তাহলে Guess Button-এর নিচে "Too Low" লেখা দেখাবে। যদি সঠিক সংখ্যা তোমার অনুমানের চেয়ে ছোট হয়, তাহলে Guess Button-এর নিচে "Too High" লেখা দেখাবে। এভাবে অনুমান করতে থাকো যতক্ষণ না সঠিক সংখ্যা বের করতে পারো। যত কম চেষ্টায় জিততে পারবে, তত ভালো স্কোর হবে এবং Leaderboard-এ জায়গা পাওয়ার সুযোগ বাড়বে।

🎮 মাল্টিপ্লেয়ার মোড

একজন Room Create করবে এবং Room Code অন্যদের সাথে শেয়ার করবে। সবাই Room Code ব্যবহার করে Join করবে। প্রত্যেকে নিজের Secret Number সেট করবে। সব Player Secret Number সেট না করা পর্যন্ত Game Start হবে না। এরপর সবাই একে অপরের Secret Number অনুমান করবে। যে সবচেয়ে কম Attempt-এ সব Secret Number বের করতে পারবে, সে Winner হবে।
